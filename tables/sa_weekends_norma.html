SA_WEEKENDS_NORMA

Таблица для фикирования нормы отпускных дней по конкретному сотруднику. / Актульно только для АЗ, т.к. у них норма отпускных дней формируется из многих критериев и кадровику нужно дать возможность руками прописывать ее для каждого сотрудника в отдельности
