UX$ACTIONPARAM

Связи (соответствие) параметров между двумя объектами. / Используется при совершении действий из одного объекта относительно второго объекта. / Например из окна поиска открыть другое окно для редактирования. / В этой таблице хранится информация - какое поле из поисковика передать окну редактирования как значение ключевого поля.

Определение

Показать DDL (CREATE TABLE) 
CREATE TABLE UX$ACTIONPARAM (
    UAP_UA_UUID          D_UUID NOT NULL,
    UAP_PARAM_NAME       D_STR_CODE NOT NULL,
    UAP_IS_OUTPUT        D_BOOL DEFAULT 0 NOT NULL,
    UAP_OWNER_UFP_UUID   D_UUID,
    UAP_OWNER_EXT_FIELD  D_STR_CODE,
    UAP_DEFAULT          D_STR_100,
    UAP_USE_DEFAULT      D_BOOL DEFAULT 0 NOT NULL,
    UAP_LOCKED           D_BOOL DEFAULT 0 NOT NULL,
    UAP_EXEC_PARAM_ID    D_SMALLINT DEFAULT 0 NOT NULL
);

ALTER TABLE UX$ACTIONPARAM ADD CONSTRAINT PK_UX$ACTIONPARAM PRIMARY KEY (UAP_UA_UUID, UAP_PARAM_NAME);
ALTER TABLE UX$ACTIONPARAM ADD CONSTRAINT FK_UX$ACTIONPARAM_OWNER_UFP FOREIGN KEY (UAP_OWNER_UFP_UUID) REFERENCES UX$FRPARAM (UFP_UUID) ON DELETE CASCADE ON UPDATE CASCADE;
ALTER TABLE UX$ACTIONPARAM ADD CONSTRAINT FK_UX$ACTIONPARAM_UA FOREIGN KEY (UAP_UA_UUID) REFERENCES UX$ACTION (UA_UUID) ON DELETE CASCADE ON UPDATE CASCADE;
