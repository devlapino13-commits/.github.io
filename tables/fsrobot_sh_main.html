FSM_KIND

Тип выполнения: / 1-Отчет Excel, высылаемый на e-mail / 2-Ежедневные отчеты, высылаемые через процедуру fsrobot_auto_send / Примечание: для fsm_kind = 2 таблица fsrobot_sh_detail не заполняется. / Поле fsm_fsr_config должно содержать имя конфигурации, передаваемое в / процедуру fsrobot_auto_send. / 3-SQL-запрос, выполняемый по расписанию (NoWait-транзакция). Запрос должен находиться в fsm_sql. / 4-Рассылка e-mail, выполняемая по расписанию. Запрос, должен находиться в / fsm_sql, и возвращать поля: mail_list, mail_subject, mail_body / 5-Рассылка sms, выполняемая по расписанию. Запрос должен находиться в fsm_sql, / и возвращать поля: phone_no, sms_text / 6-GCM рассылка сообщений (SQL) / 7-GCM синхронизация топиков / 8-Обновление геопозиции адресов (Yandex) / 9-Проверка статуса доставки sms (SQL) / 10-Выплаты на Эльсом-кошельки / 11-SQL-запрос, выполняемый по расписанию (Wait-транзакция). Запрос должен находиться в fsm_sql.
FSM_MAIL_LIST
VARCHAR(1200)
—
- Список получателей отчета для fsm_kind=1 (обязательный); / - Список получателей отчета о рассылке для fsm_kind=2 (не обязательный), / если не указан, то отчет о рассылке не высылается; / - Для fsm_kind=(3,4,5) не используется
FSM_MAIL_SUBJECT
VARCHAR(100)
—
Тема отправляемого письма(fsm_kind=1,2), или название задачи, для отчета о выполнении/ошибке
FSM_SCHEDULE
VARCHAR(50)
—
Расписание в формате cron (дополнительно добавлены секунды) / / Подробности: / http://www.cromis.net/blog/downloads/cron-scheduler/ / http://www.nncron.ru/help/RU/working/cron-format.htm / Примеры: / 0 1 * * * * * - будет вызываться в 0 секунд каждой минуты / 0 30 22 * * * * - будет вызываться в 22:30 ежедневно / 0 30 22 * * 7 * - будет вызываться в 22:30 по воскресеньям / 0 */2 * * * * - будет вызываться каждые две минуты с момента старта сервиса
FSM_IS_ACTIVE
SMALLINT
—
Расписание активно = 1, или нет = 0
FSM_FSR_CONFIG
VARCHAR(30)
—
Имя конфигурации, для вызова fsrobot_auto_send, когда fsm_kind=2
FSM_SQL
BLOB SUB_TYPE TEXT SEGMENT SIZE 80
—
- SQL запрос исполняемый по расписанию для fsm_kind = 1 / - SQL запрос, возвращающий mail_list, mail_subject, mail_body для e-mail / рассылок, когда fsm_kind = 4 / - SQL запрос, возвращающий phone_no, sms_text для sms-рассылок, / когда fsm_kind = 5 / - Для fsm_kind = 3 не используется / - Для fsm_kind = 2, и fsm_is_external = 1, содержит текст письма / - Для fsm_kind = 2, и fsm_is_external = 0, не используется
FSM_IS_EXTERNAL
INTEGER
—
Тип рассылки, для fsm_kind = 2 / 0 - Внутренняя рассылка, для пользователей Компании / 1 - Внешняя рассылка, для клиентов, тогда в fsm_sql хранится текст письма
